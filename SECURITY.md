# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
[private vulnerability reporting](../../security/advisories/new) on this repository and include steps to reproduce.
You'll get a response as soon as possible; please give a reasonable time to fix before disclosing.

## Supported versions

Only the latest release (3.x) receives security fixes.

## Handling secrets

No credentials are stored in this repository. See [docs/SECRETS.md](docs/SECRETS.md).
If you find a secret in the code or history, report it privately as above.
