# Secrets & credentials

Rule: **no secret value ever goes into git.** Only names of variables are committed (`render.yaml`, `.env.example`).

| Secret | Where it lives | Notes |
| --- | --- | --- |
| `DATABASE_URL` (Neon) | Render dashboard → settlehub-backend → Environment | Entered once when the Blueprint is created (`sync: false`). Rotate in Neon (reset role password) then update Render. |
| `JWT_SECRET` | Render (auto-generated by `render.yaml`) | Rotating it signs everyone out. |
| `BREVO_API_KEY`, `BREVO_SENDER_EMAIL` | Render dashboard | Without the key, nobody receives OTP emails. |
| `APP_ADMIN_EMAILS` | Render dashboard | Who is admin. Never add an email that can be squatted or bypassed. |
| `VAPID_*`, `FCM_SERVICE_ACCOUNT_JSON` | Render dashboard (use a *Secret File* for the FCM JSON if preferred) | Enables background push. |
| Android keystore (`*.jks`) + passwords | Password manager / GitHub Actions secrets | Already gitignored. Back it up: losing it means you can't update the app. |
| Test/admin account passwords | `.env.local` (gitignored) or a password manager | See below. |

## Local development
1. `cp .env.example .env.local` and fill in only what you need.
2. `scripts/dev-backend.sh` starts the backend on H2 with the bypass list and a dev master OTP **and ignores `DATABASE_URL`**, so local runs cannot modify the Neon database.
3. `npm --prefix frontend run dev`.

`.env.local` may hold the production `DATABASE_URL` for tooling; keep file permissions private (`chmod 600 .env.local`).

## Production rules
- `AUTH_MASTER_OTP` and `APP_AUTH_VERIFICATION_BYPASS_EMAILS` must stay **unset** on Render. The bypass list and master OTP were the cause of account-takeover paths and are for local/test only.
- Use long random passwords for the admin account (`openssl rand -base64 24`) and keep them in a password manager (macOS Keychain, 1Password, Bitwarden). Short memorable passwords on a production admin are the weakest link.
- Free options that fit this project: Render environment variables / Secret Files, Neon's role password reset, GitHub Actions encrypted secrets, macOS Keychain (`security add-generic-password -s settlehub -a admin -w`).
